## Сохранность выбора шаблона — 2026-10-15

Шаблон из URL применяется один раз до редактирования Markdown или типа документа.
Явный выбор шаблона остаётся авторитетным: эффект не возвращает исходный шаблон.
Поздний ответ каталога не затирает ввод, включая намеренно очищенный текст;
пользователь по-прежнему может применить загруженный шаблон кнопкой.
Четыре регрессионных случая воспроизведены до исправления. После исправления
прошли все 239 frontend-тестов, lint, TypeScript, OpenAPI check и production build.

включая задержанный ответ шаблонов, ручной выбор, save payload, сохранность
назначения, предпросмотр, empty draft и конфликты публикации. Скриншоты выбора
шаблона 375/1920/2560 просмотрены; собственный preview остановлен.

## Создание документа: неизменный отправленный черновик

Во время создания документа его поля, назначение и применение шаблона временно
недоступны. Успешный ответ переводит на созданный документ, поэтому ввод после
отправки не должен создавать несохранённую версию, теряемую при переходе.
Обработчик также отклоняет повторный submit, пока первый запрос выполняется.
При ошибке поля снова доступны с прежними значениями. API и backend не меняются.
Проверки: блокировка редактирования и повторного submit; браузерные сценарии
с задержанным успехом и ошибкой создания, сохранность полей и save payload.

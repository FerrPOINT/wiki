# Очистка навигации

Основная навигация: обзор, проекты, пространства и один поиск. Проект содержит обзор, документы с деревом и материалы. Подборки по задачам и фазам доступны через «Дополнительно» в документах и самостоятельных Spaces. Шаблоны и администрирование находятся в «Служебном»; профили, настройки и аудит — внутри администрирования. `search_scope=project|all` задаёт область поиска независимо от project_scope. Старые URL сохраняются; общий поиск открывает ресурс с его фактической привязкой.

Функции, данные, API и права доступа сохраняются. Служебная группа свёрнута по умолчанию, раскрывается при прямом входе и допускает ручное сворачивание. На desktop и mobile используется одно состояние. Проверки: точные ресурсы при одинаковых названиях, старые ссылки, Back/Forward, all-projects scope, доступность, роли и narrow/wide UI.

# Исправления первого круга багфайндинга SDLC2

Авторизация: пользователь попросил исправить подтверждённые дефекты и перейти к следующему кругу.

1. При проекции каталога Central Auth нормализовать отображаемое имя:
   непустое trimmed display_name, затем username, затем email для старого контракта.
   Identity, статус, права, credentials и ограничения БД сохраняются.
2. Добавить регрессии пустого/пробельного имени и PostgreSQL-проверку смешанного
   каталога, повторной синхронизации и disabled-записи на отдельной QA-БД.
3. Показывать безопасные русские сообщения INTERNAL_ERROR и UNAVAILABLE,
   сохраняя детали валидации полей.
4. Проверить frontend tests/typecheck, Rust fmt/clippy/tests, затем собрать и
   применить только wiki-backend/wiki-web через helper SDLC2.
5. Повторить SSO, каталог, пространства и администрирование в отдельном профиле
   браузера. Результаты записать в приватный отчёт workspace.

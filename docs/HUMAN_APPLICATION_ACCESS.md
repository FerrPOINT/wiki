# Две роли и приложения: интеграция Wiki

Статус: исходники feature-ветки; не установленная политика.
Канон: Base `docs/platform/HUMAN_APPLICATION_ACCESS.md` и ADR0011.

## Владелец полномочий

Central Auth выдаёт текущую роль `user`/`admin` и допуск `wiki`.
PAT дополнительно ограничен своими scopes. HTTP403 не вызывает повторный SSO.
Машинные owner/reader credentials остаются отдельными ограниченными субъектами.

`require_wiki_auth` один раз получает проверенные context/name/proof, передаёт
через `WikiBackendPort` только профиль и связывает локальный UUID с исходной
SDK authority на срок запроса. Profile port не принимает роль и не создаёт права.
Профиль выбирается по `central_sub`; email не связывает историческую учётку.
Новый профиль и материализация каталога используют локальный `user`.
Повторный вход обновляет профиль без повышения или переписывания старых ролей.

В central mode `active_global_role` использует SDK request authority, а SQL
списков/поисковых областей/каталогов получает проверенное boolean-решение.
Сохранённый `global_role=admin` не является центральным назначением. Настройки,
управление пользователями, общие шаблоны, пространства и их участники требуют
текущего `admin`; прежний space member admin не повышает центрального пользователя.
Документы, версии, дерево, evidence и вложения остаются рабочими ресурсами и
дополнительно проверяют доступ к данным и lifecycle.

## Совместимость и приёмка

Standalone без Central Auth сохраняет собственную явную локальную авторизацию.
Исторические UUID, авторы, роли, документы, ACL и миграции не переписываются.
Новые пространства и admission данных разрабатываются отдельно; этот слой
не заменяет и не включает их политику.

До активации обязательны SQL/HTTP проверки на заполненных копиях, интеграция
namespace admission, исходный срок полномочий у DB commit/download streams,
UI и обычный/admin IAB. Проверка после handler не является commit guard и не
доказывает безопасность отложенной операции. Результаты находятся в отчёте
workspace, а не считаются выполненными по наличию этой документации.

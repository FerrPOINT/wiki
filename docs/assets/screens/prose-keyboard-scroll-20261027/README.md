# Клавиатурная прокрутка подготовленного HTML

Настоящий Prose Base с синтетическими данными, фактическая ширина iframe
375px, dark. Снимок — отдельная source-компонентная проверка; приложение,
продуктовые API, Auth и пользовательские данные не использовались.

Проверены также light/gray и ширины 320/1920/2560px, обе страницы Wiki с
синтетическими hook-адаптерами, Tab, прокрутка стрелками, focus при смене
темы, обновление HTML и reset. Полный кадр сохранён без кадрирования.

# Task and phase dossier URL history QA

Дата проверки: 2026-09-23.

## Область проверки

- `/tasks` и `/phases` с реальным Central Auth и Wiki API;
- поиск по всему пространству и cursor pagination;
- direct URL, reload, browser Back/Forward и явный переход `Назад`;
- переход в досье и возврат к исходному списку;
- сохранение соседних query-параметров;
- размеры интерактивных целей, responsive, темы, accessibility и runtime/API ошибки.

## Исходное поведение

На production bundle параметры поиска и страницы оставались только в React state.
После поиска и перехода на вторую страницу URL не менялся, а reload очищал поиск и
возвращал первую страницу. Машинный результат сохранён в `baseline-report.json`.

## Реализованный контракт

- `q` хранит нормализованный поисковый запрос;
- `cursor` хранит текущую cursor-страницу;
- повторяемый `previous_cursor` хранит явный стек переходов назад;
- изменение поиска сбрасывает cursor history через replace;
- пагинация и смена пространства создают ожидаемые browser history entries;
- неизвестные соседние query-параметры сохраняются;
- ссылки на досье и возвратные ссылки переносят контекст каталога;
- невалидные и пустые параметры канонизируются без лишней записи в history.

## Результат

- функциональные сценарии: 2/2;
- визуальная матрица: 18/18 состояний, 2 route x 3 темы x 3 ширины;
- ширины: 375, 1920 и 2560 px;
- horizontal overflow: 0;
- интерактивные цели меньше 40 px: 0;
- serious/critical Axe violations: 0;
- page/runtime errors: 0;
- HTTP errors: 0;
- неожиданные write requests: 0.

Полный машинный результат находится в `candidate-report.json`. Представительные
снимки сохранены для mobile, desktop и ultra-wide в light, gray и dark themes.
Прогон был read-only и не изменял данные Wiki.

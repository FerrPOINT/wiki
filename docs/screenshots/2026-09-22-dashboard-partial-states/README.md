# Wiki dashboard: частичные ошибки

Проверка выполнена 22 сентября 2026 года на общем Docker-стенде `sdlc-ux` с реальным SSO и реальными данными Wiki. Для error-состояний подменялся только один GET endpoint; пространства и остальные секции продолжали работать с живым backend.

## Матрица

| Состояние | Тема | Ширины |
| --- | --- | --- |
| Все данные доступны | light | 375, 1920, 2560 px |
| Недоступен счётчик фаз | dark | 375, 1920, 2560 px |
| Недоступны задачи | light | 375, 1920 px |
| Недоступен поиск документов | gray | 375, 1920 px |

В каждом частичном отказе endpoint отвечал `503` на начальный запрос и три штатных повтора TanStack Query. После фиксации состояния локальная кнопка повтора переключалась на реальный backend; все сценарии восстановились без перезагрузки страницы.

## Результат

- 10 из 10 состояний прошли проверку.
- Горизонтального переполнения страницы и вложенных элементов нет.
- На ширине 375 px интерактивных целей меньше 40 px нет.
- Серьёзных и критических нарушений axe нет.
- Неожиданных HTTP-, console- и page-ошибок нет.
- Ожидаемые console-сообщения относятся только к четырём намеренным ответам `503` в каждом error-сценарии.

Машиночитаемые метрики находятся в [results.json](results.json). PNG-файлы в этой папке содержат полноразмерные снимки каждого состояния.
